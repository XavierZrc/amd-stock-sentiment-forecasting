AMD Stock Return Prediction Using News Sentiment

This project explores whether sentiment from Hacker News discussions can help predict AMD stock returns. I combined sentiment scores from news headlines with financial data, then tested a few different forecasting models — ARIMAX, XGBoost, and LSTM — to compare their performance.

Sentiment was classified using FinBERT, and models were evaluated using RMSE, MAE, and directional accuracy. 

Built with Python (pandas, scikit-learn, transformers) in Google Colab, as a group final project.
